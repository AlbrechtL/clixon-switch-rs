# clixon-switch-rs

This project is meant to run in Yocto. The recipe for it lives in
[meta-ethernet-switch-os](https://github.com/AlbrechtL/meta-ethernet-switch-os);
the build that puts it into a switch image is
[ethernet-switch-os](https://github.com/AlbrechtL/ethernet-switch-os), a kas
project.

It can also be run in a container environment.
